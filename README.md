优学院自动学习助手 (Ulearning Auto Player)

一个用于优学院平台的用户脚本，可实现视频自动播放、静音、调速、自动翻页以及自动完成练习题。

✨ 功能特性

自动播放与翻页：自动播放当前章节视频，完成后自动进入下一页
视频控制：支持自动静音、自定义播放速率（最高15倍速）
自动答题：可自动完成选择题、判断题及填空题，并提供显示答案选项
智能检测：能识别平台标记为“已完成”的视频并自动跳过
课程完成检测：学完所有课程后自动暂停脚本，并给出提示
控制面板：页面右上角提供可视化控制面板，可随时调整设置或暂停脚本

📥 安装与使用

1. 确保你的浏览器已安装 Tampermonkey 或 Violentmonkey
2. 点击下方链接安装脚本：
   [点击安装](https://raw.githubusercontent.com/Keep-exploring/dgut-/main/ulearning-auto-player.js)
3. 打开优学院课程页面，脚本将自动运行
